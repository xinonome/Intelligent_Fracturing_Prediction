# 智能体决策流程示意图

这张图对应当前 `HMI-KE/rl` 的真实执行链路。动作不是直接控制设备，而是先经过泵序和安全边界约束，再进入 PKN/EnKF 数字孪生环境进行响应评估。

```mermaid
flowchart LR
    A[历史压裂秒点\n当前及过去300秒\n压力/排量/砂比/工艺特征]
    B[数字孪生状态\n当前压力、排量、砂比\n后验缝长、EnKF误差\n井底压力、净压力\n异常概率、砂堵概率]
    C[智能体策略\nPPO/SAC\n或分层策略选择器]
    D[原始动作\naQ, aSB ∈ [-1,1]\n未来60秒排量/砂比建议]
    E[动作安全约束\n最大排量/砂比\n单步变化幅度\n连续/间隔加砂\n高风险时降砂或停砂]
    F[PKN正演\n累计注入量\n当前排量\n滤失/应力阴影\n分簇导流反馈]
    G[EnKF在线更新\n更新E'、CL、mu、sigma_min\n及分簇进液/携砂参数]
    H[后验PKN重算\n输出后验缝长、缝宽\n井底压力、净压力]
    I[工况风险模型\n异常概率\n砂堵概率\n模型不确定性]
    J[综合奖励\n改造效果\n压力安全\n异常风险\n施工成本\n泵序匹配]
    K{安全与可信判断}
    L[继续策略学习\n记录transition\n更新PPO/SAC]
    M[保持/降低动作\n人工确认\n不直接下发设备控制]
    N[180秒验证\n连续3个60秒窗口\n压力/风险是否超限]

    A --> B --> C --> D --> E
    E --> F --> G --> H --> I
    H --> J
    I --> J
    J --> L
    H --> K
    I --> K
    K -->|安全且观测可信| L
    K -->|模型不确定| M
    K -->|压力或异常风险超限| M
    M --> N
    L --> N
    N --> B
```

## 一次决策的含义

在时刻 `t`，智能体看到的是过去 300 秒构成的状态，不是单个压力点。策略输出两个归一化动作：

```text
aQ  -> 未来60秒排量调整方向
aSB -> 未来60秒砂比调整方向
```

例如当前排量为 `12 m3/min`、砂比为 `5%`，策略输出：

```text
aQ = 0.6
aSB = -0.4
```

系统不会把 `0.6` 当作 `0.6 m3/min`。它首先映射到当前允许的工程范围，再执行泵序约束。结果可能是：

```text
建议排量 = 13.2 m3/min
建议砂比 = 4.2%
```

之后才进入数字孪生环境。

## 数字孪生反馈

数字孪生环境对动作的处理顺序是：

```text
动作后的排量/砂比
  -> 更新累计注入体积
  -> 计算历史等效排量和当前排量
  -> PKN计算各簇裂缝扩展
  -> 生成压力和分簇观测
  -> EnKF更新物理参数
  -> 用后验参数重新运行PKN
  -> 计算风险、奖励和安全标记
```

这里 EnKF 的后验输出不是直接将缝长改成观测值，而是更新参数后重新计算：

```text
x = [E', CL, mu, sigma_min, f1...f6, s1...s6]
x_prior -> EnKF -> x_posterior
PKN(x_posterior) -> 后验缝长/压力/开度
```

## 决策结果的三种去向

### 1. 安全且可信

动作、压力和异常风险均未超限，EnKF 后验误差可接受。该动作进入训练记录，策略继续学习。

### 2. 模型不确定

例如后验误差超过 `0.30`。这不等于现场已经发生异常，而是说明当前模型和观测不一致。系统输出保持或降低动作，并要求人工确认。

### 3. 操作不安全

例如井底压力、净压力、异常概率或砂堵概率超过阈值。系统触发风险标记和安全惩罚；严重压力超限时可提前终止当前仿真窗口。

## 与现场系统的边界

当前实现是：

```text
策略建议 -> 约束检查 -> 数字孪生评估 -> 人工确认
```

当前尚未实现：

```text
策略直接控制压裂泵组
自动修改现场施工参数
真实在线闭环执行
```

因此汇报时应称为“知识嵌入智能体与数字孪生安全决策原型”，不能表述为已经具备现场自动控制能力。
