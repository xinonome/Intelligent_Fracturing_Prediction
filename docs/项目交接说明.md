# 项目交接说明

## 数据边界

- `Data/raw_frac`：合同第一、三部分使用的分段施工秒点，属于保密数据。
- `Data/3Dfrac`：第8段光纤分簇监测、施工压力和井轨迹，属于保密数据。
- `Data/multimodal`：允许使用的书籍源文件、解析文本和图片。
- 代码发布时排除整个 `Data`；数据清单由 `build_data_manifest.py` 生成。

## 核心接口

- 第一部分：`FSL-Expert/frac_gnn` 和五个保留训练入口。
- 第二部分：`DT-Crack/inversion/physics.py`、`validate_direct_observations.py`、`benchmark_forward_models.py`。
- 第三部分：`HMI-KE/rl`、`decision_engine`、`simulator` 和 `train_rl_control_agent.py`。
- 联合入口：`run_project.py`。

## 维护规则

- 原始数据只能进入 `Data`。
- 新实验只能写入 `outputs`，不得在源码目录创建 `runs`。
- 可交付的小体积结果进入 `artifacts`，并附带指标和来源说明。
- 不在代码中保存API密钥、甲方URL或绝对数据副本。

## 当前限制

- 真实裂缝长度标签缺失，数字孪生只验证液砂分布和井底压力观测空间。
- reduced BEM和数据代理用于接口与性能验证，不是生产级高保真正演器。
- 智能体仍是离线训练与仿真，不直接下发设备控制指令。
