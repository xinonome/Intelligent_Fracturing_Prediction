# FSL-Expert GitHub Release

This is a sanitized code release for contract part 1:

- expert-knowledge-enhanced small-sample learning
- GNN / LGBM working-type recognition pipelines
- transfer learning, resampling, data augmentation, hierarchical abnormal classification
- public book-derived knowledge graph artifacts

Excluded:

- confidential fracturing Excel data
- raw Data/ directory
- model weights and serialized artifacts
- experiment uns/
- private PPT/DOCX/PDF files

The book itself can be distributed separately if needed. GitHub hard-limits individual files to 100MB, so large raw book/PDF/image assets should be uploaded through GitHub Releases, Git LFS, or external storage instead of committing them into the repository.

To run training, place authorized private data under the expected Data/ layout and update project_config.yaml.
