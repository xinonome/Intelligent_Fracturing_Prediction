# FSL-Expert 合同条款映射

## 1. 基于图神经网络(GNN)的专家知识图谱

- 已有 `frac_gnn` 模块用于按段构造 1 到 6 点历史窗口，并以 `WORKING_TYPE` 为目标标签训练工况识别模型。
- 已有知识图谱、标签分布、转移概率、异常类别统计图用于表达专家知识和数据规律。
- 当前工程口径：专家知识图谱用于提供工况定义、异常类别解释、转移关系和小样本先验。

## 2. 基于迁移学习的小样本学习框架

- `train_frac_gnn_transfer.py` 实现源域预训练和迁移集微调。
- 数据按段划分为训练、验证、测试、迁移学习集，避免同一段泄漏到多个子集。
- 迁移学习结果用于评估跨段适配能力。

## 3. 专家知识驱动的数据增强与重采样机制

- 支持类别权重：少数类权重更高。
- 支持异常过采样：提高少数异常工况在训练过程中的出现频率。
- 支持异常数据增强：对少数类窗口加入轻量噪声生成增强样本。
- 支持加砂后截断和动态特征：减少大量加砂前正常样本对异常识别的稀释。

## 4. 高效压裂施工多模态数据库

- `Data/raw_frac` 保存压裂分段 Excel、总表和便签补充数据。
- `Data/knowledge_graph` 保存知识图谱实体、关系、HTML 可视化和问答数据。
- `Data/multimodal` 保存文档 OCR、图像解析和多模态图谱中间产物。
- `Data/manifests/data_manifest.json` 记录数据来源、用途、字段、目标列和所属模块。

## 当前限制

- 异常类别存在明显长尾和小样本问题，少数工况只出现在个别段。
- 当前专家知识主要以标签、规则、统计分布和转移概率形式进入建模流程，后续可继续加强图嵌入与模型融合。
- 多模态数据库已具备图文资料和施工数据，但不同模态之间的统一 ID 和时空对齐仍需完善。
