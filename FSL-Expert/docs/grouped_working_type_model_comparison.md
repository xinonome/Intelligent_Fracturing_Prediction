# 分组工况预测模型对比

## 对比目的

为了公平评估“两级串联工况预测模型”是否优于普通多分类模型，需要保证两类模型使用相同标签口径。

当前统一标签为：

```text
正常
砂堵
缝口暂堵
缝内暂堵
其他异常
```

其中小样本异常统一合并为 `其他异常`。

## 已完成模型

### 1. 直接分组多分类模型

脚本：

```text
FSL-Expert/train_direct_grouped_working_type_lgbm.py
```

模型逻辑：

```text
输入施工特征窗口 -> 直接预测 5 类分组工况
```

结果目录：

```text
FSL-Expert/runs/direct_grouped_working_type_lgbm/20260625_130702
```

测试集结果：

```text
Macro-F1 = 0.5774
Accuracy = 0.8062
```

### 2. 两级串联硬门控模型

脚本：

```text
FSL-Expert/train_hierarchical_grouped_abnormal_lgbm.py
```

模型逻辑：

```text
第一层：正常 / 异常
第二层：砂堵 / 缝口暂堵 / 缝内暂堵 / 其他异常
```

硬门控方式：

```text
第一层判断为正常 -> 直接输出正常
第一层判断为异常 -> 进入第二层
```

结果目录：

```text
FSL-Expert/runs/hierarchical_grouped_abnormal_lgbm/20260625_084928
```

测试集结果：

```text
第一层正常/异常 Macro-F1 = 0.7477
第二层 oracle Macro-F1 = 0.3864
最终串联 Macro-F1 = 0.5234
Accuracy = 0.7855
```

### 3. 两级串联概率融合模型

脚本：

```text
FSL-Expert/train_hierarchical_grouped_abnormal_lgbm.py
```

改进逻辑：

```text
第一层输出 P(正常)、P(异常)
第二层输出 P(异常类别 | 异常)
最终异常类别分数 = P(异常) * P(异常类别 | 异常) * 异常放大系数
```

验证集自动选择异常放大系数。

结果目录：

```text
FSL-Expert/runs/hierarchical_grouped_abnormal_prob_fusion_lgbm/20260625_134736
```

测试集结果：

```text
硬门控 Macro-F1 = 0.5234
概率融合 Macro-F1 = 0.5376
概率融合 Accuracy = 0.7972
```

### 4. 两级串联概率融合调优模型

调优内容：

```text
正常样本下采样比例：0.3 -> 0.1
类别权重指数：1.0 -> 1.5
类别权重最大倍率：30 -> 80
异常分数放大系数搜索范围扩大到 20
```

结果目录：

```text
FSL-Expert/runs/hierarchical_grouped_abnormal_tune_a/20260625_143855
```

测试集结果：

```text
第一层正常/异常 Macro-F1 = 0.7385
第二层 oracle Macro-F1 = 0.4203
硬门控 Macro-F1 = 0.5380
概率融合 Macro-F1 = 0.5528
概率融合 Accuracy = 0.7878
```

## 当前结论

| 模型 | Macro-F1 | Accuracy | 说明 |
|---|---:|---:|---|
| 直接分组多分类 | 0.5774 | 0.8062 | 当前最优 |
| 两级串联硬门控 | 0.5234 | 0.7855 | 第一层漏检会直接阻断第二层 |
| 两级串联概率融合 | 0.5376 | 0.7972 | 比硬门控提升，但仍低于直接多分类 |
| 两级串联概率融合调优 | 0.5528 | 0.7878 | 继续接近直接多分类，但仍未超过 |

当前不能声称两级串联优于直接多分类。更准确的结论是：

```text
两级串联结构经过概率融合和异常召回调优后，相比硬门控有明显提升，但在当前数据集和 LightGBM 设置下，直接分组多分类仍是最优基线。
```

## 原因分析

两级串联的主要瓶颈是第一层正常/异常判断。

如果第一层把异常判断成正常，第二层就没有机会修正。即使第二层能识别砂堵、缝口暂堵等异常，也会被第一层漏检限制。

直接多分类模型没有这种门控损失，可以直接把样本预测为异常类别，因此当前结果更高。

## 后续改进方向

1. 优化第一层异常召回
   - 调整异常类权重。
   - 提高异常过采样比例。
   - 使用更低阈值或召回优先损失。

2. 第二层只训练高置信异常样本
   - 剔除标签噪声明显的异常样本。
   - 对砂堵、缝口暂堵、缝内暂堵分别做 one-vs-rest 子模型。

3. 融合直接多分类与两级模型
   - 直接多分类作为主模型。
   - 两级模型作为异常复核模型。
   - 当两个模型同时预测异常时提高置信度。

4. 引入专家规则
   - 砂堵规则用于修正砂堵类概率。
   - 缝口暂堵和缝内暂堵规则需要继续从案例库中提取。

## 汇报口径

```text
我们补充了公平对比实验：在同样合并小样本异常为“其他异常”的标签口径下，比较直接多分类、两级硬门控和两级概率融合三种方案。结果显示，两级模型经过概率融合和异常召回调优后，Macro-F1 从硬门控的 0.523 提升到 0.553，说明两级结构有改进空间；但当前仍低于直接分组多分类的 0.577。因此现阶段直接分组多分类是最优基线，两级结构后续应作为异常复核模型，或继续和直接多分类进行集成融合。
```
