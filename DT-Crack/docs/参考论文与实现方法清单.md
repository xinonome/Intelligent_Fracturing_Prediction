# 合同第二部分参考论文与实现方法清单

## 一、核心参考论文

### 1. DAS 驱动的裂缝几何反演

**论文**：Hu, Xiaodong et al. *A Hydraulic Fracture Geometry Inversion Model Based on Distributed-Acoustic-Sensing Data*，SPE Journal，DOI: [10.2118/214306-PA](https://doi.org/10.2118/214306-PA)。

**论文方法**：

```text
LF-DAS/HF-DAS 信号 + 注入排量
    -> 提取应变/信号特征
    -> 裂缝几何正演
    -> 计算 DAS 预测值与观测值残差
    -> 迭代调整裂缝长度、宽度等参数
    -> 重新正演
```

可表示为：

\[
\hat{\theta}=\arg\min_\theta
\sum_t\left\|y_t^{DAS}-H_{DAS}(F_{frac}(\theta,u_t))\right\|^2
+\lambda R(\theta)
\]

**本项目对应实现**：

- PKN 作为裂缝几何正演模型；
- 使用多个时间步进行参数拟合；
- 参数更新后重新计算缝长、缝宽、面积和体积；
- 当前用分簇液量份额、砂量份额和井底压力替代原始 DAS 信号特征。

**当前缺口**：项目目前没有原始 LF-DAS/HF-DAS 应变率矩阵，因此不能声称已经复现论文的原始 DAS 观测算子。当前实现是工程数据适配版。

**对应代码**：

- `DT-Crack/inversion/physics.py`
- `DT-Crack/inversion/validate_direct_observations.py`
- `DT-Crack/inversion/compare_literature_inversion_methods.py`

---

### 2. DTS + EnKF 裂缝参数同化

**论文**：Tarrahi, M.; Gildin, E.; Moreno, J.; Gonzales, S. *Dynamic Integration of DTS Data for Hydraulically Fractured Reservoir Characterization with the Ensemble Kalman Filter*，SPE 169990-MS，DOI: [10.2118/169990-MS](https://doi.org/10.2118/169990-MS)。

**论文方法**：

建立非等温裂缝/井筒正演模型，将裂缝几何和导流能力映射为温度剖面：

\[
y_t^{DTS}=H_{DTS}(F_{thermal}(x_t,u_t))+\varepsilon_t
\]

然后用 EnKF 更新裂缝半长、裂缝渗透率、导流能力等参数：

\[
K_t=P_{xy,t}(P_{yy,t}+R)^{-1}
\]

\[
x_t^a=x_t^f+K_t(y_t^{DTS}-\hat{y}_t)
\]

**本项目对应实现**：

```text
PKN参数集合
    -> PKN裂缝几何、压力、分簇分配正演
    -> 液量/砂量/井底压力观测算子
    -> EnKF更新PKN参数
    -> 更新参数重新运行PKN
```

当前 EnKF 状态包括：

```text
E'、滤失系数 CL、流体黏度 mu、最小水平主应力
分簇生长/入口参数、分簇砂量输运参数、压力偏置
```

**重要区别**：当前项目没有 DTS 温度，因此不是 DTS 温度反演的完整复现，而是借鉴 DTS-EnKF 的“参数更新而非直接改缝长”结构。

**对应代码**：

- `DT-Crack/inversion/physics.py` 中的 `enkf_update()`、`denkf_update()`；
- `DT-Crack/inversion/validate_direct_observations.py`；
- `DT-Crack/data_fusion/fiber_observation_operator.py`。

### 3. VAE/KAN + EnKF 快速数据同化

**论文**：Zhou, Ziqiang et al. *Data-Driven Real-Time Inversion of Hydraulic Fracture Geometry and Stress Fields Using a Deep-Kolmogorov-Arnold Network Assisted Data Assimilation Approach*，SPE 228112-MS；相关期刊扩展为 *Characterizing the Hydrodynamic and Mechanical Properties of Hydraulic Fractured Shale Plays Using a Kolmogorov-Arnold-Network-Assisted Data Assimilation Approach*，DOI: [10.1016/j.engappai.2025.110380](https://doi.org/10.1016/j.engappai.2025.110380)。

**论文方法**：

```text
大量裂缝网络图像/应力场样本
    -> VAE编码为低维潜变量 z
    -> KAN代理模型预测施工压力
    -> EnKF同化真实压力
    -> 更新 z 和应力参数
    -> VAE解码为裂缝网络
```

形式上：

\[
z=Encoder(I_{frac})
\]

\[
\hat{p}=KAN(z,\sigma,u)
\]

\[
z^a=z^f+K(p_{obs}-\hat{p})
\]

**本项目对应情况**：

- 已有参数空间 EnKF，结构上可以承接该路线；
- 已有 `data_surrogate` 代理模型接口；
- 已有 PKN、reduced BEM 生成代理训练样本的能力。

**尚未完整实现的部分**：

- 没有论文所需的大规模裂缝网络图像数据；
- 没有 VAE 的裂缝图像编码/解码器；
- 没有 KAN 代理模型；
- 没有独立应力场和裂缝网络真值。

因此当前 `data_surrogate` 只能称为 PKN/BEM 工程代理模型，不能称为论文中的 VAE/KAN 复现。

**对应接口**：

- `DT-Crack/forward_models/fracture_length_models.py`
- `DT-Crack/forward_models/cache/`
- `DT-Crack/inversion/benchmark_forward_models.py`

### 4. DAS 全时间步裂缝尖端反演

**论文**：Liu, Yongzan; Liang, Lin; Zeroug, Smaine. *Enhancing Understanding of Hydraulic Fracture Tip Advancement through Inversion of Low-Frequency Distributed Acoustic Sensing Data*，[arXiv 版本](https://arxiv.org/abs/2305.13138)。

**论文方法**：

- 使用低频 DAS 判断裂缝尖端推进；
- 使用三维位移不连续/边界元风格正演；
- 通过迭代优化使模拟信号与 DAS 观测匹配；
- 输出裂缝半长、推进速度、截面积和体积等量。

**本项目对应实现**：

- 保留 `reduced-order BEM` 正演接口；
- 使用 PKN 输出缝长、缝宽、面积和体积；
- 当前通过时间步回放展示裂缝连续扩展；
- 新增全时间步最小二乘 PKN 反演基线。

**当前缺口**：没有原始 LF-DAS 信号和位移不连续边界条件，因此目前是“方法结构适配”，不是完整三维边界元反演复现。

## 二、辅助参考论文

### 5. EnKF 反问题的一般理论

**论文**：Iglesias, M. A.; Law, K. J. H.; Stuart, A. M. *The Ensemble Kalman Filter for Inverse Problems*，[arXiv](https://arxiv.org/abs/1209.2736)。

**可借鉴方法**：

- 用集合表示参数不确定性；
- 通过集合协方差建立参数—观测关系；
- 不要求手工推导复杂模型梯度；
- 适合非线性正演和在线更新。

**本项目应用**：`physics.py` 中的随机 EnKF 和确定性 DEnKF 更新，参数更新后重新调用 PKN。

---

### 6. 基于 EnKF 的水力压裂裂缝系统反演

**论文**：Xue, L.; Li, D. *The Application of Ensemble Kalman Filter to Inversion of Fracture System in Shale Gas Reservoir*，DOI: [10.1007/978-981-10-7560-5_153](https://doi.org/10.1007/978-981-10-7560-5_153)。

**可借鉴方法**：

- 将裂缝系统参数作为状态变量；
- 通过观测数据不断修正裂缝系统；
- 重点关注参数化方式和观测算子，而不是直接替换几何结果。

**本项目应用**：将状态扩展为全局 PKN 参数、分簇参数和动态压力偏置，避免只更新一个缝长缩放因子。

---

### 7. 基于 EnKF 的倾斜仪裂缝映射

**论文**：Pandurangan 等. *Mapping Hydraulic Fractures from Tiltmeter Data Using the Ensemble Kalman Filter*，[Wiley](https://onlinelibrary.wiley.com/doi/10.1002/nag.2415)。

**论文方法**：

```text
裂缝几何参数
    -> 弹性半空间位移/倾斜正演
    -> 倾斜仪观测
    -> EnKF更新裂缝几何
```

**本项目可借鉴点**：建立“几何状态—传感器观测”的明确观测算子。当前项目的液量/砂量/压力观测算子也应逐步替换为 DAS 真实信号算子，而不是直接把等效缝长当成真值。

**当前状态**：尚未实现倾斜仪数据模块，项目没有倾斜仪数据。

---

### 8. POD 降维 + EnKF 反馈控制

**论文**：*POD-based EnKF Estimation of Heterogeneous Reservoir Parameters for Feedback Control of Hydraulic Fracturing*，[ScienceDirect](https://www.sciencedirect.com/science/article/pii/B9780444642417501178)。

**论文方法**：

- 用 POD 将高维空间变化的杨氏模量或储层参数压缩为少量基系数；
- EnKF 只更新低维 POD 系数；
- 更新后的场进入高保真正演和反馈控制。

**本项目可借鉴点**：如果甲方提供多井、多段和空间应力场数据，可以将当前单一 `E'`、`sigma_min` 扩展为：

\[
E'(s)=E'_0(s)+\sum_{k=1}^{r}a_k\phi_k(s)
\]

EnKF 更新 \(a_k\)，而不是为每个网格直接增加大量状态变量。

**当前状态**：暂未实现，因为现有数据不足以建立可信空间参数场。

---

### 9. DAS 流体到达实时 Kalman 反演

**论文**：*Where Is the Fluid? Using Distributed Acoustic Sensing-Based Strain Measurement in Near Real Time*，SPE Journal，DOI: [10.2118/212350-PA](https://doi.org/10.2118/212350-PA)。

**论文方法**：

- 从 DAS 轴向应变识别流体接近监测井的位置；
- 对观测关系进行线性化；
- 使用 Kalman 滤波实时估计流体到达状态。

**本项目可借鉴点**：先把 DAS 原始信号转为“流体到达/活动区间/空间权重”，再作为 PKN-EnKF 的观测输入，而不是直接从分簇液量构造等效缝长。

**当前状态**：等待原始 DAS 振幅/应变矩阵和空间坐标。

## 四、当前结论

当前最适合作为主线的不是单独照搬某一篇论文，而是组合其有效思想：

```text
PKN/后续 BEM 正演
  + DAS/DTS/压力观测算子
  + 参数空间 EnKF
  + POD 或代理模型降维加速
  + 动态数字孪生和在线修正
```

当前实现已经完成论文思想在现有数据上的工程适配，但以下内容仍需甲方数据支持后才能进一步实现：

- 原始 DAS 应变率矩阵和空间坐标；
- DTS 温度剖面和温度正演参数；
- 独立裂缝长度/宽度/几何解释真值；
- 多井、多段空间应力和岩石参数；
- 用于训练 VAE/KAN 的裂缝网络样本。
