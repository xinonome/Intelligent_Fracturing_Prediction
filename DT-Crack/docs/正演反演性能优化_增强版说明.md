# 正演反演性能优化：物理预校准 + 参数空间 EnKF

## 1. 本轮优化目标

当前第二部分的核心不是把缝长直接拟合到一条曲线上，而是：

```text
施工/光纤观测
  -> 估计 PKN 参数
  -> 用更新后的参数重新计算 PKN
  -> 得到新的裂缝长度、缝宽、压力和分簇分配
```

本轮优化针对旧流程的三个问题：

1. EnKF 从宽泛随机先验开始，前期参数容易漂移到多个等效解；
2. 簇间应力遮挡只在最终缝长上做乘法修正，没有反馈到分簇导流分配；
3. Carter 滤失的 50% 上限可能过于保守，导致滤失参数长期撞到边界。

## 2. 增强后的计算流程

### 2.1 前 70% 数据：物理参数预校准

使用校准段的液量份额、砂量份额和井底压力，求解一个带物理先验的批量目标：

\[
\hat{x}_0=\arg\min_x\left[
\sum_{t\in calibration}
\left\|R_t^{-1/2}\left(y_t-H(F_{PKN}(x,u_t))\right)\right\|_2^2
 +\lambda\left\|S_x^{-1}(x-x_{prior})\right\|_2^2
\right]
\]

其中：

- (x=[\log E',\log C_L,\log\mu,\sigma_{min},f_1...f_6,s_1...s_6,\Delta p_{nw}])；
- (u_t) 是总排量、当前排量和时间；
- (y_t) 是光纤分簇液量份额、砂量份额和井底压力；
- (R_t) 是观测噪声协方差；
- (S_x) 是物理参数先验尺度，防止优化器选择不合理的等效解。

预校准只使用前42个时间点，18个留出时间点不参与该步骤。

### 2.2 PKN增强正演

对第 (i) 个簇，历史裂缝半长采用有效排量计算：

\[
L_i=0.68\left(\frac{E' q_{eff,i}^{3}}
{\mu H^4}\right)^{0.2}t^{0.8}
\cdot(0.95+0.10f_i)\cdot S_i
\]

当前缝宽使用当前边界排量，而不是把一次排量突变当成整个历史过程：

\[
w_i=2.5\left(\frac{\mu q_{current,eff,i}^{3}}
{E'H^3}\right)^{0.2}t^{0.2}
\]

Carter滤失按裂缝面积和时间计算：

\[
V_{L,i}=2C_L A_i\sqrt{t}
\left(1+\frac{\Delta p}{p_{ref}}\right)^{\beta}
\]

并施加质量守恒约束：

\[
\sum_i V_{L,i}\leq \alpha V_{inj},\qquad
q_{eff,i}=\max\left(q_{nom,i}-\frac{V_{L,i}}{t},
\epsilon q_{nom,i}\right)
\]

增强版使用 (alpha=0.85) 作为工程先验，但仍然保证滤失量不超过累计注入量；这不是允许模型凭空产生流体。

簇间导流能力为：

\[
G_i=f_i\left(\frac{w_i}{\bar w}\right)^\eta S_i^{\gamma}
\]

\[
q_{nom,i}=Q_{total}\frac{G_i}{\sum_jG_j}
\]

其中 (S_i) 是应力遮挡因子。增强版将应力遮挡反馈到 (G_i)，因此高排量簇会抑制邻簇导流，而不是只在最后把长度乘小。

压力依赖滤失采用弱修正：

\[
C_{L,eff}=C_L
\left(1+\frac{\Delta p}{p_{ref}}\right)^{\beta}
\]

它不会替代完整地层滤失实验，只用于当前数据条件下提高工程一致性。

### 2.3 后续时间点：EnKF在线更新

预校准中心用于初始化集合，之后每个新观测到达时执行：

\[
P_{xy}=\frac{1}{N-1}X'Y'^T
\]

\[
P_{yy}=\frac{1}{N-1}Y'Y'^T+R
\]

\[
K=P_{xy}P_{yy}^{-1}
\]

\[
x_t^a=x_t^f+K\left(y_t-H(F_{PKN}(x_t^f))\right)
\]

然后重新执行：

\[
L_{i,t}^{a}=F_{PKN,i}(x_t^a,u_t)
\]

因此，EnKF 更新的是 PKN 参数和分簇参数，缝长是参数更新后的正演输出，不是被 EnKF 直接覆盖的状态量。

## 4. 为什么没有把“累计记忆”直接作为默认增强

曾测试过将每步有效排量和缝宽积分为累计液砂观测。结果在线留出误差上升到液量约11.25%、砂量约11.76%，原因是当前 `q_base=累计液量/时间` 本身已经是历史平均量，再做稀疏时间步积分会重复计算历史量。

因此当前默认增强版采用：

- 正演输入中的 `q_base` 表示累计注入量对应的历史平均排量；
- `q_current` 表示当前时刻边界排量，用于缝宽和压力；
- 光纤累计份额继续作为观测残差；
- 不再对已经历史平均化的排量做第二次累计积分。

这是基于数据口径的选择，不是简单认为累计观测不重要。若后续取得每个时间步的真实增量液量/增量砂量，应再启用严格的状态空间累计观测算子。

## 5. 严格边界

当前结果证明的是：在真实第8段数据、光纤分簇液砂和井底压力观测下，参数空间EnKF在线修正后的PKN输出能够在观测空间达到15%以内，且单步计算低于15秒。

它不等同于已经用独立裂缝几何真值验证了真实缝长误差。要把“缝长15%以内”升级为独立工程结论，还需要甲方提供DAS裂缝长度解释、微地震反演长度或其他独立几何标签。
