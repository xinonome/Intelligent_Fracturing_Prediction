# PKN、面板离散BEM与数据代理正演对比

## 1. 三类模型定位

| 模型 | 计算方法 | 在线用途 |
|---|---|---|
| PKN | 固定缝高解析尺度律 | 最快基线与实时保底模型 |
| 面板离散BEM | 裂缝翼面板离散、弹性影响矩阵、润滑压力迭代、簇间应力遮挡 | 高保真降维教师模型 |
| 物理引导MLP代理 | 学习面板BEM相对PKN的非线性修正量 | 接近BEM响应的快速在线模型 |

## 2. 面板离散BEM

每条对称裂缝翼沿缝长方向离散为36个常开度面板。面板压力与开度满足离散弹性关系：

\[
\mathbf{w}=\frac{1}{E'}\mathbf{G}\mathbf{p}
\]

其中，\(\mathbf{G}\) 是由面板间距离和自面板解析积分构成的对数型平面应变影响矩阵。流动采用润滑近似：

\[
\frac{\mathrm{d}p}{\mathrm{d}x}=\frac{12\mu q}{w^3}
\]

程序在压力和开度之间执行最多18次固定点迭代，并加入由簇间距构造的应力遮挡矩阵。分簇入口系数只重新分配实测总排量：

\[
Q_i=Q_{\mathrm{total}}\frac{Q_{i,0}f_i}{\sum_j Q_{j,0}f_j}
\]

因此所有簇的排量之和始终等于施工总排量。

当前模型固定裂缝高度、采用对称双翼和降维流动近似，属于可在线运行的数值BEM，不等同于完整三维生产级边界元求解器。

## 3. 物理引导数据代理

代理模型不是直接拟合缝长，而是学习BEM相对PKN的对数修正：

\[
\hat L=L_{\mathrm{PKN}}\exp(f_{\theta,L}(\mathbf{x})),\qquad
\hat w=w_{\mathrm{PKN}}\exp(f_{\theta,w}(\mathbf{x}))
\]

输入包括分簇入口系数、邻簇耦合系数、簇位置、局部和邻簇排量、黏度、弹性模量、缝高、时间以及PKN基线状态。网络为三隐层MLP：`128 -> 64 -> 32`。

训练集由面板BEM生成1100组联合变化工况。验证按完整工况分组留出220组，避免同一工况不同簇同时进入训练集和验证集。独立留出结果：

- 缝长平均相对误差：0.42%；
- 缝长P95相对误差：1.00%；
- 开度平均相对误差：0.18%。

这些指标表示代理对当前面板BEM教师的逼近能力，不表示相对于现场真实裂缝几何的误差。

## 4. 第8段真实控制量对比

统一使用第8段光纤时间序列、6簇、80个EnKF集合成员、20个时间步和20次耗时重复：

| 模型 | 单次正演P95 | EnKF单步P95 | 最终后验观测误差 | 15秒达标 |
|---|---:|---:|---:|---|
| PKN | 0.28 ms | 28.32 ms | 10.85% | 是 |
| 面板离散BEM | 4.16 ms | 391.95 ms | 9.51% | 是 |
| 物理引导MLP代理 | 0.74 ms | 58.09 ms | 9.36% | 是 |

结果表明，面板BEM通过数值弹性耦合降低了观测空间误差；代理模型在保持接近BEM响应的同时，显著降低EnKF需要重复调用正演模型的计算开销。
