# 正反演模型缺点与精度优化

> 最新增强版结果和复现命令见 [正演反演性能优化_增强版说明.md](正演反演性能优化_增强版说明.md)。当前推荐使用 `--physics-profile enhanced`：前70%做物理参数预校准，随后以参数空间EnKF在线修正PKN；不要将在线后验结果解释为脱离观测的长期外推精度。

## 1. 优化前发现的问题

1. 快速演示链路的等效缝长由“PKN先验缝长×光纤活动因子”构造，适合演示校正过程，但不能作为独立真实几何精度证据。
2. 基础PKN固定缝高，并用平均缝宽近似净压力，无法解释排量基本不变时出现的瞬时压力跳变。
3. 原随机EnKF允许液量、砂量、压力残差通过有限集合的虚假协方差共同更新所有参数，部分随机种子会收敛到高滤失等价解。
4. 原稳健残差处理同时降低液砂份额大残差的权重，容易把真实分簇不均衡误判成离群点。
5. 冻结验证表明，静态分簇参数无法跨施工阶段预测持续变化的液砂分配；合同实时修正应采用在线先验—后验双指标，而不能只报告后验。

## 2. 已实施优化

- 面板离散BEM：36面板弹性影响矩阵、润滑压力—缝宽迭代和簇间应力遮挡。
- 物理引导MLP代理：以面板BEM为教师，学习相对PKN的残差修正，按完整工况分组留出。
- EnKF观测噪声校准：集合成员400，液砂份额噪声0.015，压力噪声3.5 MPa。
- 动态近井筒压力修正：新增 \(\Delta p_{nw}\) 状态，隔离孔眼冲蚀、摩阻参数变化和未建模压降，避免错误修改裂缝几何参数。
- 分通道稳健处理：液砂份额保留完整更新权重，仅对压力通道的极端创新使用稳健降权。
- Carter滤失质量守恒先验：累计滤失不超过累计注入量的50%，阻止不可辨识的高滤失等价解。
- 输出先验与后验两套指标：先验表示观测到达前预测，后验表示实时同化后的数字孪生状态。

## 3. 真实第8段在线留出结果

统一采用42步校准、18步在线留出、400个集合成员。优化前默认结果：

| 指标 | 优化前 | 优化后 seed=2026 | 优化后 seed=2027 |
|---|---:|---:|---:|
| 后验液量TVD | 2.35% | 1.77% | 1.71% |
| 后验砂量TVD | 3.08% | 1.93% | 1.99% |
| 后验井底压力误差 | 6.30% | 1.63% | 1.68% |
| 每步全部观测≤15% | 94.44% | 100% | 100% |
| 单步P95耗时 | 175 ms | 227 ms | 238 ms |

优化后仍远低于15秒计算指标。两种随机种子的结果接近，说明不再依赖单次幸运集合采样。

## 4. 必须保留的技术边界

- 以上精度是液量分配、砂量分配和井底压力的直接观测空间误差，不是独立实测裂缝长度误差。
- 动态近井筒压力修正是模型误差状态，不应解释为地层最小应力或裂缝净压力。
- 50%滤失上限目前是工程先验；获得滤失试验、岩心参数或历史拟合结果后必须重新校准。
- 当前只有一个井段，尚不能证明跨井、跨区块泛化能力。
- 冻结留出误差高于在线后验误差，说明系统定位应为“观测持续到达条件下的在线数字孪生校正”，而不是无观测长期外推模型。
