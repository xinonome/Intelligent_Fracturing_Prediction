# 第三部分：知识嵌入智能体后续实施计划

## 1. 计划目标

围绕合同第三部分“基于知识嵌入智能体的人机互动精准控制方法”，将当前的规则决策原型和 Gymnasium 强化学习环境继续完善为可复现、可验证、可演示的智能控制模块。

当前动作定义为未来 60 秒的：

- 排量 `flow_m3_min`
- 砂比 `sand_ratio_percent`

当前状态定义为：

- 当前及历史 300 秒施工压力、排量、砂比
- PKN-EnKF 裂缝状态和后验误差
- 井底压力、净压力
- 异常工况概率和砂堵概率
- 分簇均衡程度、模型不确定性和风险等级

最终目标不是简单提高训练奖励，而是验证智能体能够在不同工况下给出安全、可解释、可执行的调整建议，并满足“动作调整后连续 180 秒不出现异常”的验收要求。

## 2. 当前基础与主要问题

### 2.1 2026-07-27 实施进展

- 已新增六类场景方向性验证入口，检查有限输出、缝长不可逆和风险响应方向。
- 已区分正常裂缝传播与低流量/停泵模式；低流量时跳过 PKN 扩展计算，保持裂缝几何并执行压力松弛。
- 已将 EnKF 后验误差从现场 `unsafe` 中拆分为模型 `uncertain`，用于保持动作和人工确认。
- 已增加严格180秒失败窗口、高不确定窗口和六场景安全率图输出。
- 已增加训练质量门、源码 SHA-256 指纹、课程训练和多随机种子训练入口。
- 六类仿真场景基础验收目前为 6/6 通过；正式长步数策略和100%连续180秒安全率仍待训练验证。
- 已完成七阶段课程训练 smoke test；课程模型总体180秒安全率达到83.33%，5类场景达到100%，砂堵场景仍未通过。
- 已加入风险加权回放：砂堵权重3，压力上限、分簇不均衡、暂堵转向权重2。追加512步验证后总体180秒安全率达到90.28%，砂堵场景达到42%，其余5类保持100%。当前平均奖励仍略低于历史动作，质量门未通过。

当前已经具备：

1. Gymnasium 连续动作环境。
2. PPO/SAC 训练入口和模型检查点保存。
3. 轻量分层策略：高层选项包括 `hold`、`grow`、`divert`、`safe`。
4. PKN-EnKF 数字孪生动作响应环境。
5. 六类工况配置：历史基线、正常扩展、砂堵风险、分簇不均衡、压力接近上限、暂堵转向。
6. 综合奖励：改造效果、压力安全、异常风险、施工成本和泵序约束。
7. 严格 180 秒验证，只统计完整的连续 3 个 60 秒决策窗口。
8. 高风险动作抢占安全选项，并允许应急降低排量和砂比。

当前尚未达到验收级的原因：

- 训练步数和随机种子数量仍不足，已有结果主要是 smoke test 或阶段性训练。
- 六类场景的风险响应仍是工程仿真，需要用真实段级数据和专家规则校准。
- 砂堵风险存在记忆效应，降砂后的风险消散速度需要进一步校准。
- 180 秒安全率尚未达到 100%，不能将阶段结果表述为验收通过。
- 当前高层策略仍属于轻量 HRL 原型，不是完整的端到端 HRL。
- 当前输出为建议和人工确认，不直接控制现场设备。

## 4. 阶段一：完善多工况仿真环境

### 4.1 场景数据生成

以第一部分压裂秒点数据作为基础样本，按段、时间顺序和 `WORKING_TYPE` 划分场景。每类场景保留原始施工趋势，仅对压力、排量、砂比、风险概率和裂缝扩展参数施加可解释扰动。

六类场景的用途如下：

| 场景 | 主要训练目标 | 关键约束 |
|---|---|---|
| 历史基线 | 学习历史动作分布 | 不改变原始趋势 |
| 正常裂缝扩展 | 保持稳定施工并扩大有效裂缝 | 平滑升排量、逐级加砂 |
| 砂堵风险 | 及时降砂、控压和恢复 | 禁止继续激进加砂 |
| 分簇不均衡 | 识别不均衡并转向 | 控制风险、不盲目增砂 |
| 压力接近上限 | 控制压力和净压力 | 优先降排量、保留安全余量 |
| 暂堵转向 | 保持阶段稳定并请求确认 | 高风险操作必须人工确认 |

### 4.2 环境改进要求

- 每个 episode 不得跨段、跨场景取样。
- 场景参数必须记录到 `scenario_name` 和 `scenario_spec`。
- 风险必须同时受状态和动作影响，不能只由固定时间趋势决定。
- 降排量、降砂动作应使风险概率按物理和工程规则下降。
- 极端压力可以提前终止，普通风险保留在轨迹中，让智能体学习恢复。
- 安全选项应具有动作投影能力，保证高风险状态至少执行最小幅度的降排量、降砂。
- 对低流量或停泵状态增加单独处理，避免把 PKN 失效状态误判为正常扩展。

### 4.3 阶段验收

- 六类场景均能完成 `reset -> step -> episode`。
- 随机动作、历史动作和安全动作的响应方向符合预期。
- 砂堵场景下执行降砂后，砂堵概率在后续窗口下降。
- 场景生成具有固定随机种子，可重复生成。
- 环境测试全部通过，并保存测试摘要。

## 5. 阶段二：完善奖励函数和安全约束

奖励统一表示为：

```text
总奖励 = 改造效果奖励
       - 压力安全惩罚
       - 异常风险惩罚
       - 施工成本惩罚
       + 泵序平滑与历史动作一致性奖励
```

### 5.1 改造效果

由 PKN-EnKF 输出的裂缝半长、缝宽、增长率、分簇均衡程度计算。不能只奖励裂缝越长，还要限制缝宽、压力和分簇差异，避免策略通过过度加砂获得虚假的高奖励。

### 5.2 压力安全

同时检查：

- 井底压力上限。
- 净压力上限。
- 压力变化速率。
- 连续多个窗口接近上限的累计风险。

### 5.3 异常风险

使用异常概率、砂堵概率、EnKF 后验误差和分簇不均衡程度。风险达到边界时，智能体进入 `safe` 或 `divert` 选项，并触发人工确认。

### 5.4 施工成本

考虑排量和砂比变化幅度、频繁调整次数、偏离历史施工区间的程度。成本项用于避免策略不停振荡或无必要地大幅调整。

### 5.5 阶段验收

- 奖励各组成项在每一步写入日志。
- 任意危险动作不能获得正向安全奖励。
- 安全动作具有明确的风险改善效果。
- 奖励函数在正常、砂堵、压力上限场景下排序合理。

## 6. 阶段三：完成强化学习训练

### 6.1 训练顺序

1. 使用历史基线和正常扩展场景进行预训练。
2. 加入压力上限和分簇不均衡场景。
3. 最后加入砂堵风险和暂堵转向场景。
4. 使用六类场景混合训练。
5. 使用多个随机种子独立训练，按最差场景和最差种子筛选模型。

### 6.2 推荐训练配置

```powershell
cd C:\Workspace\Intelligent_Fracturing_Prediction

python run_project.py hmi full-train `
  --algorithm ppo `
  --total-timesteps 100000 `
  --seeds 2026 2027 2028 `
  --episode-steps 60 `
  --eval-episodes-per-scenario 10 `
  --n-envs 2
```

训练时必须保留：

- 每个随机种子的模型权重。
- checkpoint。
- 训练日志。
- 六类场景评价结果。
- 180秒严格验证结果。
- 奖励组成和危险动作统计。

### 6.3 训练验收标准

- 训练步数达到预设值，不能用几百或几千步结果代替正式训练。
- 训练集、验证集、测试集按段隔离。
- 至少3个随机种子重复训练。
- RL策略平均奖励高于历史基线，或能明确解释收益来源。
- 危险步比例低于历史基线。
- 180秒安全率按场景分别统计，不能只报告总体平均值。

## 7. 阶段四：严格180秒安全验证

每个决策动作对应60秒，验证窗口固定为3步：

```text
t       执行动作 a_t
t+60    观测响应并更新风险
t+120   继续观测和校正
t+180   检查整个窗口是否出现异常
```

每个完整窗口必须满足：

- 井底压力不超过上限。
- 净压力不超过上限。
- 异常概率不超过阈值。
- 砂堵概率不超过阈值。
- 不出现未确认的高风险动作。

输出指标：

- 总体180秒安全率。
- 六类场景180秒安全率。
- 各场景最大压力、最大异常概率、最大砂堵概率。
- 调整前后风险变化。
- 动作变化幅度和人工确认次数。

验收门槛：所有正式测试场景和随机种子的安全率达到100%。若未达到，必须保留失败窗口并分析原因，不能通过修改阈值掩盖问题。

## 8. 阶段五：知识嵌入与人机协同接口

### 8.1 决策输出

统一输出 JSON：

```json
{
  "scenario": "sand_plug_risk",
  "current_state": "携砂阶段",
  "recommended_flow_m3_min": 12.0,
  "recommended_sand_ratio_percent": 3.0,
  "predicted_risk_level": "high",
  "uncertainty": "medium",
  "main_risk": "砂堵风险升高",
  "requires_confirmation": true,
  "evidence": {
    "bottomhole_pressure_mpa": 103.2,
    "sand_plug_probability": 0.41,
    "posterior_error": 0.12,
    "high_level_option": "safe"
  }
}
```

### 8.2 权限规则

- `viewer`：只能查看状态和建议。
- `engineer`：可以确认普通建议。
- `supervisor`：可以确认高风险建议。
- 高风险动作必须二次确认。
- 当前阶段只输出建议，不直接控制现场设备。

### 8.3 阶段验收

- 风险高于阈值时必须 `requires_confirmation=true`。
- 所有推荐动作带有可追溯证据字段。
- 禁止动作不能被接口下发。
- 能回放完整决策链：状态 -> 风险 -> 选项 -> 动作 -> 180秒结果。

## 11. 当前不能承诺的内容

在真实施工数据、光纤同步数据和专家物理边界尚未完全校准前，不能承诺：

- 智能体已经可以现场自动控制。
- 180秒安全率已经达到100%。
- 策略已经具备跨井、跨区块泛化能力。
- 当前仿真风险概率等同于真实工况概率。

当前正确的交付口径是：已形成融合 PKN-EnKF、知识规则、安全约束和 PPO/SAC 的离线智能控制原型，下一阶段通过环境校准、长步数多种子训练和严格180秒验证推进到验收级。
