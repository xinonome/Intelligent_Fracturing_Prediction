# 异常工况风险口径

## 1. 分类原则

正常施工窗口仍然作为控制模型的负样本和安全基线保留，但不计入异常风险正类。当前统一口径为：

| 类别 | 当前处理 | 说明 |
| --- | --- | --- |
| 空白、正常、正常工况 | 正常 | 空白标签按正常处理 |
| 主缝延伸 | 正常施工 | 表示目标裂缝继续扩展，不作为异常风险 |
| 砂堵 | 异常风险 | 重点风险类别 |
| 缝口暂堵 | 异常风险 | 需要关注压力和进砂响应 |
| 缝内暂堵 | 异常风险 | 需要关注簇间分配和压力变化 |
| 延伸受阻 | 异常风险 | 裂缝扩展能力下降 |
| 滤失过大 | 异常风险 | 注入液体有效利用率下降 |
| 缝高延伸 | 异常风险 | 可能存在超出目标层段的扩展风险 |
| 其他、异常、新缝开启 | 异常风险/待细分 | 保留风险，不静默归为正常 |

当前 `Data/raw_frac` 的标签清单中可见 `主缝延伸、砂堵、缝口暂堵、缝内暂堵、延伸受阻、滤失过大、缝高延伸、其他` 等标签；空白标签按照项目数据说明处理为正常。

## 2. 风险模型输入

异常概率目标由显式 `WORKING_TYPE` 异常标签生成：

```text
future_abnormal = 1
  当未来60秒窗口包含显式异常标签
future_abnormal = 0
  当未来60秒窗口只有空白、正常或主缝延伸
```

砂堵概率仍是异常风险中的专项子概率：

```text
future_sand_plug = 1
  当窗口包含砂堵标签
```

井底压力越限、分簇不均衡、EnKF后验误差和OOD不再冒充 `WORKING_TYPE` 标签，而是作为动态风险信号单独进入智能体环境。

## 3. 暂堵的边界

当前数据没有稳定的“计划暂堵/非计划暂堵”字段，因此 `缝口暂堵` 和 `缝内暂堵` 暂按异常风险处理。甲方若能提供泵序、暂堵剂投加时间或施工意图字段，下一版可拆分为：

```text
planned_diversion       计划内暂堵，不直接判定为危险
unplanned_plugging      非计划暂堵，进入异常风险
```

## 4. 训练和验收口径

- 正常样本不删除，继续用于学习安全动作和降低误报。
- 正常样本不再增加异常概率，也不触发异常风险惩罚。
- 180秒验证中的异常失败只由显式异常风险、压力越限、砂堵概率和其他动态安全边界触发。
- 旧版响应代理使用了“非正常即异常”的标签口径，需要重新训练后才能用于正式实验。

代码入口：`condition_taxonomy.py`、`data_pipeline.py`、`simulator/fsl_scenario_library.py`、`response_surrogate.py`。
