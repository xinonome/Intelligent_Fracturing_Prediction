# HMI-KE 合同条款映射

## 混合型分层强化学习智能体框架

当前阶段不直接训练完整 HRL，而是采用三阶段路线：

1. 规则 + 知识图谱 + 不确定性评估的智能决策原型。
2. 历史回放/模拟场景下的策略推荐智能体。
3. 接入 HRL/强化学习，用于多工况策略训练和策略优化。

当前已实现第一阶段，智能体按“状态感知、风险评估、策略推荐、人工确认”分层。

## 不确定性认知与感知

- 基于工况转移概率判断模型置信度。
- 基于 EnKF 残差判断模型与观测偏差。
- 输出 `low / medium / high` 三档不确定性。

## 人机协同决策接口

- 高风险建议必须人工确认。
- 控制类动作必须二次确认。
- 角色权限分为 `viewer`、`engineer`、`supervisor`。
- 输出推荐动作、禁止动作、确认等级和证据字段。
- 当前模式为 `advisory_only`，不直接下发设备控制。

## 多工况仿真平台

- `simulator/synthetic_scenarios.py` 提供正常、砂堵预警、裂缝延伸等模拟场景。
- `historical_replay.py` 预留历史 Excel/CSV 回放能力。
